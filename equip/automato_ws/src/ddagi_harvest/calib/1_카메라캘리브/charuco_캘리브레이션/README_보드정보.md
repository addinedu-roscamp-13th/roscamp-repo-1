# ChArUco 캘리브레이션 보드 (로봇팔용)

## 파일
- `charuco_3장_인쇄용.pdf` — A4 3페이지(동일 보드 3장). 이거 인쇄.
- `charuco_board.png` — 미리보기 1장.

## 보드 사양 (캘리브레이션 소프트웨어에 그대로 입력)
| 항목 | 값 |
|---|---|
| Dictionary | DICT_5X5_100 |
| Squares (가로 x 세로) | 5 x 7 |
| Square length | **30 mm** (0.030 m) |
| Marker length | **23 mm** (0.023 m) |
| 보드 실측 | 150 x 210 mm |

## ★ 인쇄 주의 (정확도의 핵심)
1. **반드시 '실제 크기(100%)' 인쇄** — 프린터 대화상자의 "용지에 맞춤/축소" 끄기.
2. 인쇄 후 **자로 한 칸이 정확히 30mm인지 확인** (아니면 그 실측값을 소프트웨어에 입력).
3. **빳빳한 판(폼보드/아크릴)에 평평하게 부착.** 종이가 휘면 정확도 급락.
4. 3장은 **완전히 동일(같은 마커 ID)** — 한 화면(카메라 뷰)에 2장 이상 동시에 두지 말 것(검출 혼동).

## 용도별 사용 (1장 재사용 가능)
- **① 카메라↔카메라**: 두 카메라가 같은 보드 1장을 동시에 보게 → 상대 위치 계산.
- **③ 카메라↔BASE (핸드아이)**: 보드 고정 후 로봇을 여러 자세로 움직여 촬영 → 카메라-베이스 변환 계산.
- 두 용도 모두 **같은 보드 재사용 OK**.

## 로봇팔 2개일 때
- 카메라↔카메라: 보드 1장으로 1회.
- 카메라↔BASE: **각 팔마다 base 좌표계가 다르므로 팔별로 따로 1회씩** (보드는 재사용). 총 2회.
- 카메라가 팔에 붙었나(eye-in-hand) / 고정(eye-to-hand)에 따라 절차 세부가 다름.
