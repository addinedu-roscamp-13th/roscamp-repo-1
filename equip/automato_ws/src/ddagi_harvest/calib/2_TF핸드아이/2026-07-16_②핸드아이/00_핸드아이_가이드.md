# ② 카메라↔베이스 핸드아이 캘리브 (easy_handeye2 + ChArUco)

날짜: 2026-07-16 · 로봇: JetCobot @192.168.100.12 · 카메라: D435i (그리퍼 장착, eye-in-hand)

## 무엇을 구하나
카메라(그리퍼에 달림)와 로봇 베이스 사이의 고정 변환 **gripper→camera (X)**.
이게 있어야 카메라로 본 물체 좌표를 로봇 좌표로 바꿔 집을 수 있다.

## 원리 (eye-in-hand, AX=XB)
- 보드는 테이블에 **고정**. 로봇이 여러 자세로 움직이며 그 보드를 카메라로 본다.
- 각 자세 i 에서 두 변환을 얻는다:
  - `base_T_gripper(i)` : 로봇 자세 (arm_tf_bridge 가 SSH로 읽어 TF 발행)
  - `camera_T_target(i)`: 카메라가 본 보드 자세 (charuco_tf_publisher 가 검출해 TF 발행)
- 보드가 고정이므로 `base_T_gripper · X · camera_T_target` 이 모든 i 에서 같아야 한다는
  제약(AX=XB)을 풀어 X = gripper_T_camera 를 구한다. → easy_handeye2 가 담당.

## 구성요소 (전부 로컬, MoveIt 실물제어 없음 → JetCobot 흔들림/파손 위험 0)
| # | 프로세스 | 역할 | 발행 TF |
|---|---|---|---|
| 1 | realsense2_camera 노드 | 카메라 영상 | camera_* 프레임들 |
| 2 | charuco_tf_publisher.py | 보드 검출 | camera_color_optical_frame → handeye_target |
| 3 | arm_tf_bridge.py | 로봇자세(SSH) | base_link → gripper_link |
| 4 | easy_handeye2 calibrate | 핸드아이 solve | (rqt GUI: Take Sample/Compute) |

## 보드 규격 (네 실제 보드)
- ChArUco, **DICT_5X5_100**, **5×7** 칸, square **30mm**, marker **23mm** (①스테레오와 동일 보드)

## 실행 방법
```bash
bash ~/handeye_ws/start_handeye2.sh
```
→ 카메라·TF 노드들 자동 기동 후 **easy_handeye2 rqt 캘리브 창**이 뜬다.

## GUI 조작 순서
1. **보드를 테이블에 단단히 고정**(움직이면 안 됨). 카메라가 보드를 잘 보게 첫 자세 잡기.
2. 로봇을 **손으로/스크립트로 다른 자세**로 옮긴다 (⛔ MoveIt 아님, pymycobot 로만).
   - 자세마다 보드가 카메라에 **충분히 보이게**(코너 6개 이상). 각도·거리·회전 다양하게.
3. 보드가 잘 잡힌 상태에서 rqt 창의 **[Take Sample]** 클릭.
4. 2~3 반복해서 **15~20 샘플** 모은다. 자세는 골고루(상/하/좌/우/기울임/회전).
5. **[Compute]** → 결과 X (gripper→camera) 나옴.
6. **[Save]** → `~/.ros/easy_handeye2/jetcobot_handeye.calib` 저장.

## ⚠️ 오일러 규약 검증 (중요)
arm_tf_bridge 는 로봇 coords 의 rx,ry,rz 를 **ZYX** 규약으로 회전 변환한다(기본값).
pymycobot 규약이 다르면 회전이 틀려 결과가 조용히 잘못될 수 있다.
→ 샘플 수집 후 `base_T_gripper·X·camera_T_target` 의 자세간 퍼짐으로 검증.
   퍼짐이 크면 `EULER=xyz bash start_handeye2.sh` 처럼 규약 바꿔 재시도.
   (reg'표준 후보: ZYX, xyz, ZYZ)
